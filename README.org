#+TITLE: Kernel prebuilts for the Xiaomi Pad 7 (uke)
#+OPTIONS: toc:nil num:nil

* About

Prebuilt kernel blobs for the *Xiaomi Pad 7* (=uke=, Snapdragon 7+ Gen 3), used by
the [[https://github.com/Xiaomi-Pad-7-Development/android_device_xiaomi_uke][uke device tree]].

* Contents

| Path             | What it is                                              |
|------------------+---------------------------------------------------------|
| =kernel=         | Stock kernel image (6.1.138-android14)                  |
| =dtbs=           | Device tree blobs for the Cliffs SoC variants           |
| =dtbo.img=       | Device tree overlay image, panel patches applied        |
| =modules=        | Kernel modules: =ramdisk=, =vendor= and =system=        |
| =kernel-headers= | Kernel UAPI headers for the Android build               |
| =extract-files.sh= | Refreshes the prebuilts from a stock Xiaomi OTA zip   |

* Updating

Run the script from the root of this repository, inside an Android source tree:

#+begin_src sh
./extract-files.sh /path/to/uke-ota.zip
#+end_src

It unpacks the OTA, rebuilds =dtbo.img= with the Uke panel patches and copies the
modules into place.

* Source

Everything in this repository is taken from the stock Xiaomi OS3.0.304.0.WOZMIXM ROM:
the kernel image, the DTBs, the DTBO and the kernel modules.
